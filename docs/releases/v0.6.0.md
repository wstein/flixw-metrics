# flixw-metrics v0.6.0

This release adds compiler-backed metrics support for Flix 0.77.0 and gives modules of mounted Flix
packages readable names in module coupling.

## Highlights

- Flix 0.77.0 is supported through the existing `Flix0761Adapter`: the bytecode-derived capability
  gate accepts it with no missing members, so no new adapter family is needed. Packaged integration
  is verified at recorded checkpoints from Flix 0.60.0 through 0.77.0; Flix 0.59.0 and the broken
  0.66.0 artifact remain rejected at their documented boundaries.
- `Flix0761Adapter` is now compiled against Flix 0.76.1, the oldest release in its family, rather
  than the current compiler pin, so an API that exists only in a newer release cannot slip into it.
- Flix 0.77 names a mounted package under a root that cannot be written in source, such as
  `$pkg$github$flix$museum-clerk`. Module dependencies now show that package the way Flix does,
  as `github:flix/museum-clerk.Board`. A package module stays distinct from a project module of the
  same name, and package definitions still never count as project code. Counts are unchanged; only
  the names change, and only for projects that call mounted packages.
- The nine-target calibration corpus retained all 1,349 findings exactly. No metric definition,
  ranking, rule, threshold, report field, or CLI behavior changed.

Native JSON schema version remains 35 and the measurement-cache wire version remains 14. Existing
baselines and caches remain compatible; compiler and plugin artifact fingerprints still prevent
measurements from crossing incompatible inputs.

The project is licensed under Apache-2.0. Java 21 and flixw 0.25.10 or newer are required.

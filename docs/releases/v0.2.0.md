# flixw-metrics v0.2.0

This release makes compiler-backed Flix metrics safer to automate and substantially easier for
coding agents to consume.

## Highlights

- Native JSON schema 29 adds compact `summary`, `findings`, and baseline-aware `changes` views;
  typed rankings; a self-describing rule catalog; severity and baseline state; structured physical
  and logical locations; module dependency context; and presentation-only finding filters.
- Stable semantic finding identities survive ordinary line movement. Baselines from schemas 24–28
  migrate automatically, while filtered reports and incompatible policy snapshots are rejected.
- Baseline comparisons now include policy-independent definition, module, and summary measurement
  deltas, even when no rule threshold is crossed.
- Source digests are checked after cache-hit rendering and cold measurement. A changing tree is
  retried once, never cached prematurely, and then fails with a clear diagnostic if still unstable.
- The compiler capability gate is derived from the adapter bytecode, covering every linked ABI
  descriptor. Datalog depth and recursion use strongly connected components and topological depth.
- Release JARs are reproducible. CI now validates a generated native report against the published
  JSON Schema, while scheduled calibration exercises `--view changes` across the pinned corpus.

The project is licensed under Apache-2.0. Java 21 and flixw 0.25.10 or newer are required.

# flixw-metrics v0.4.0

This release aligns the declaration census with Flix 0.76 `stat`, exposes source-level line
evidence, and makes filtering and suppression behavior easier to audit.

## Highlights

- Declared effects now form the same partition as Flix `stat`: exact `Pure` definitions,
  ground-effectful definitions, and effect-polymorphic definitions. A bare effect variable is
  correctly non-pure even though it has no named effect constructor.
- Reports add `pureDefinitions`, `groundEffectfulDefinitions`, and
  `effectPolymorphicDefinitions`; the existing `effectfulDefinitions` remains the total of both
  non-pure categories. Full JSON also exposes `declaredPure` and `effectPolymorphic` per
  definition.
- Full JSON retains compiler-lexer line counts for every analyzed source.
- The new `largest-file` ranking points to the three largest physical source files without
  introducing a threshold or finding.
- Restrictable enums are counted independently as `restrictableEnums` across all six compiler
  adapter families, verified against real Flix releases from 0.60.0 through 0.76.0.
- A `--file` presentation filter no longer hides module-level findings, whose scope has no source
  path. Human policy summaries now disclose active suppressions as well as exclusions.
- README and compiler-SDK documentation distinguish the compact native `flixw stat` census from
  this plugin's project filtering, per-definition evidence, rankings, policy, baselines, and
  provenance.

Native JSON schema version is 35 and the measurement-cache wire version is 14. Older caches safely
miss; baselines from older report schemas must be recaptured. No new thresholds or findings are
introduced.

The project is licensed under Apache-2.0. Java 21 and flixw 0.25.10 or newer are required.

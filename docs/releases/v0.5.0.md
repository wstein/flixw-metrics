# flixw-metrics v0.5.0

This release adds compiler-backed metrics support for Flix 0.76.1 while preserving the complete
measurement and policy behavior of v0.4.0.

## Highlights

- Flix 0.76.1 is supported through a new isolated `Flix0761Adapter`. The outgoing
  `Flix0753Adapter` remains available for Flix 0.75.3 and 0.76.0.
- The adapter follows Flix's restructured source model: project declarations are selected with
  `Origin.User`, source paths use `SourceName`, and compiler-library calibration uses
  `Origin.Library`.
- Compiler construction now goes through `Bootstrap.mkFlix`, and every compiler instance is
  closed deterministically.
- The bytecode-derived capability gate now covers seven adapter families. Packaged integration is
  verified at recorded checkpoints from Flix 0.60.0 through 0.76.1; Flix 0.59.0 and the broken
  0.66.0 artifact remain rejected at their documented boundaries.
- The nine-target calibration corpus retained all 1,349 findings exactly. No metric definition,
  ranking, rule, threshold, report field, or CLI behavior changed.
- Relative project roots are covered explicitly and produce the same project-relative source
  names as absolute roots.

Native JSON schema version remains 35 and the measurement-cache wire version remains 14. Existing
baselines and caches remain compatible; compiler and plugin artifact fingerprints still prevent
measurements from crossing incompatible inputs.
